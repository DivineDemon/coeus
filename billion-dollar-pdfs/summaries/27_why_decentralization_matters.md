## Summary

Chris Dixon (2018): Decentralized crypto networks beat centralized platforms by aligning incentives with users/developers. Centralized platforms follow S-curve: attract users → extract value → fight partners. Decentralized: tokens align all stakeholders; governance by community; credible neutrality. Protocol value accrues to users (Fat Protocols). Web3 = read/write/own vs Web2 read/write.

## Key Takeaways
- Centralized platforms inevitably extract; decentralized align
- Tokens = incentive alignment + governance
- Credible neutrality: no single entity can change rules arbitrarily
- Fat Protocols: value at protocol layer, not app layer
- Web3 = user ownership (read/write/own)

## Capital Impact
Ideological foundation for Web3 investing ($100B+). a16z crypto funds ($7B+). Influenced Ethereum, Solana, Uniswap, DAO governance designs.
