## Summary

Greylock / Jerry Chen (2017): Systems of intelligence built on proprietary data and AI/ML form the durable competitive moats of the next era. Traditional moats (brand, network effects, switching costs) are eroding. New moats: data network effects (product usage → better model → better product), workflow integration, closed-loop systems. AI turns software from tool into autonomous actor.

## Key Takeaways
- Data network effects: usage generates training data → better predictions
- Closed-loop: model improves automatically with use
- Workflow integration: AI embedded in core business process
- Proprietary data > public data for defensibility
- AI = software that writes software (Software 2.0)

## Capital Impact
Greylock's AI investment thesis (Abnormal Security, Cresta, etc.). Defined 'AI-first' company architecture. Influenced $50B+ in AI application layer investing.
