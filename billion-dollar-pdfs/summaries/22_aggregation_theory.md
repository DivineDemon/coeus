## Summary

Ben Thompson (2015): Internet makes distribution free, transaction costs zero. Value chain shifts: distributors integrate forward with users, commoditizing suppliers. Aggregators (Google, Facebook, Amazon, Netflix, Uber, Airbnb) own user relationship, modularize suppliers, win on user experience. Virtuous cycle: better UX → more users → more suppliers → better UX. Winner-take-all: best aggregator serves all users globally.

## Key Takeaways
- Pre-Internet: control distribution → integrate backward to supply
- Internet: free distribution → integrate forward to users
- Aggregators commoditize suppliers (often pay nothing)
- User experience is the only moat; virtuous cycle compounds
- Winner-take-all: global scale, zero marginal cost

## Capital Impact
Defined 2010s platform investing. Explains $5T+ market cap of FAANG + Uber/Airbnb. Framework for analyzing any marketplace disruption. Stratechery built media business on this theory.

## Related Mental Models
