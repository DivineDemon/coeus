## Summary

Andrej Karpathy (2017): Neural networks are a new software paradigm where code is learned from data, not written by hand. Software 1.0 = explicit programming (if/else, loops). Software 2.0 = differentiable programs optimized by gradient descent. Advantages: handles ambiguity, differentiable end-to-end, portable to specialized hardware. The programmer becomes a data curator and loss function designer.

## Key Takeaways
- Code = learned weights; programmer = data/loss designer
- Differentiable all the way down; end-to-end optimization
- Handles 'fuzzy' problems (vision, language, control) better
- Compiles to GPU/TPU/NPU; hardware acceleration built-in
- Debugging = data inspection, loss analysis, adversarial examples

## Capital Impact
Defined Tesla Autopilot architecture (vision-only, end-to-end). Influenced all AI-first companies. Karpathy's framework used to justify AI-native product development. Shifted hiring from 'software engineers' to 'ML engineers.'

## Related Mental Models
Differentiable programming, end-to-end learning, data-centric AI, AI-native software, gradient-based optimization
