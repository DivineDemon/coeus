- **Thesis**: Knowledge-based industries run on increasing returns, not diminishing ones. The firm that gets ahead tends to get further ahead, producing winner-take-all markets.

## Summary

Balaji Srinivasan (2022 'The Network State'): Cloud communities → physical territories → diplomatic recognition. Network state = social network with moral innovation, integrated cryptocurrency, archipelago of physical enclaves, on-chain census. 'Cloud first, land last.' Exit > voice (build new vs reform old). Bitcoin/crypto as monetary sovereignty. 'The network state is the successor to the nation state.'

## Key Takeaways
- Network state: cloud community → physical enclaves → recognition
- Cloud first, land last (reverse of nation state)
- Exit > voice: build new systems vs reform old
- Crypto = monetary sovereignty
- Moral innovation = shared values
- Archipelago model: distributed physical presence

## Capital Impact
Network State concept influenced crypto city projects (Prospera, Afropolitan, Praxis). Balaji's Coinbase CTO / a16z GP background. $100M+ raised for network state projects. Book free online; 1M+ reads.
