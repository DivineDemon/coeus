## Summary

Vitalik Buterin (2013) proposed a blockchain with built-in Turing-complete programming language, enabling arbitrary smart contracts and decentralized applications. Unlike Bitcoin's limited scripting, Ethereum's accounts, messages, and state transition function allow encoding any logic: token systems, financial derivatives, identity/reputation, file storage, DAOs. Introduced gas/fees for computation, GHOST protocol for faster blocks, and addressed scalability concerns.

## Key Takeaways
- Generalized blockchain from 'currency' to 'world computer'
- Smart contracts = self-executing code with on-chain state
- Gas mechanism prevents infinite loops and prices computation
- ERC-20/721 standards emerged from this foundation
- Vision: decentralized apps (DeFi, NFTs, DAOs) built on shared substrate

## Capital Impact
Created the $400B+ smart contract platform market, enabled DeFi ($100B+ TVL), NFTs ($40B+), DAOs, stablecoins ($150B+), and Web3 ecosystem. Second-largest crypto by market cap, foundation for L2s (Arbitrum, Optimism, etc.).

## Related Mental Models
