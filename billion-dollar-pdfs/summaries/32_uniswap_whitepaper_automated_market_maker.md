## Summary

Hayden Adams (2018): Constant-product AMM (x*y=k) enabling permissionless on-chain token swaps without order books. Liquidity providers deposit token pairs; traders swap against pool; price determined by ratio. No counterparty needed; 24/7 markets; composable with other DeFi. Solved the 'chicken-and-egg' liquidity problem for long-tail tokens.

## Key Takeaways
- x*y=k: price = reserve ratio; larger trades = worse price (slippage)
- LPs earn fees (0.3%) + impermanent loss risk
- No order book = no market makers needed
- Permissionless: anyone can create pool for any token pair
- Composability: Uniswap as lego for DeFi (lending, derivatives, etc.)

## Capital Impact
Created $1T+ DeFi TVL. Uniswap $10B+ volume/day at peak. Enabled token launches, yield farming, DEX aggregation. Foundation for DeFi Summer 2020 and all subsequent AMMs (Curve, Balancer, SushiSwap).
